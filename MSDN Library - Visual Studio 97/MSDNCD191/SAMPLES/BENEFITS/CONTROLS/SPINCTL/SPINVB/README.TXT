README.TXT for Corporate Benefits Sample [ActiveX Spin Control (VB)]
Visual Studio '97

This ActiveX&#153; control is used for incrementing and decrementing currency amounts.

Use It on the Web
-----------------
It's all set up and compiled into a cabinet (.cab) file for you.
Just take the test HTML page and the .cab file and copy them to your Web server.
Change the codebase in the .htm file to point to the proper cab URL, like this:

    <OBJECT ID="spnMain"
     CLASSID="CLSID:D4BC4E93-586B-11D0-84AF-00AA00C14AF2" 	STYLE="TOP:25pt;LEFT:25pt;WIDTH:350pt;HEIGHT:200pt;ZINDEX:0;"
     CODEBASE="--INSERT URL PATH HERE--spinvb.cab#version=1,0,0,0">

Alternatively, you can use the ActiveX Control Pad to script this component for you.
Because it is an ActiveX control, you can program it from any control-compatible container.
