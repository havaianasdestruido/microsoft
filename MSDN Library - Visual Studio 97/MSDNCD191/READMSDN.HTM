Installation

  • Note   MSDN setup should not be run until you've finished installing the other applications and tools in Visual Studio.
  • If you want to access all of the Visual Studio online Help and documentation please run the MSDN Library setup. This will setup your registry keys to correctly point to the MSDN Library disc. To access the information, please keep the MSDN Library disc in your CD-ROM drive for the best performance.

Known Problems

NT Program Group creation different from previous MSDN CDs.

If you install MSDN Visual Studio Edition on NT4 and you've installed an older version of the MSDN Library (pre-Visual Studio), you'll have a Microsoft Developer Network program group in the common area (all users) for the Visual Studio edition and an old Microsoft Developer Network program group in the user specific area .

Library content referenced in multiple places in the table of contents may cause confusion when using the Synchronize Contents feature.

Your content will synchronize to the first instance of that content in the table of contents not necessarily the instance that launched the content..

Using keywords requires keyword merge

The content used by the MSDN browser (InfoViewer) is now split up into smaller pieces to make updating easier. In order to support this, a keyword merge is triggered the first time you use the Index, or the first time you press F1 to find context information about keywords in source files.

This keyword merge only happens once after you run Setup, however it can take up to 90 seconds on some systems.

Highlights and hyperlinks

Keywords (function, structure, and message names) appearing in topic text are automatically hyperlinked to their descriptions in the reference material. The utility we use to generate these hyperlinks is not context sensitive. For this reason, we've disabled hyperlinks for common words such as system, time, and exit; these words are not hyperlinked even if they appear as keywords in a topic

Some of the hyperlinks included in the Library may not function correctly. Clicking these may result in a "requested topic does not exist" error message. We are always working on correcting problems of this type in every release of the Library software.

Formatting

In some topics, you may encounter formatting problems such as truncated lines in the Topic pane or overlapping table columns resulting in overwritten text. If you encounter these problems, resize or maximize the Topic pane. In some topics, you may see lists with extraneous characters, double bullets, or double numbers. We are working on fixing these problems.

Scrolling

In some topics, the width of a graphic image may exceed the width of the Topic pane. To see the image in its entirety, increase the width of the Topic pane or maximize the Library window; you may need to use a horizontal scroll bar to view the image. An alternative method is to turn off the InfoViewer docking feature and press F2 to view the Topic pane exclusively.

Content on the move

If you cannot find any topics that you used to use, please refer to the MSDN Library Archive to find them. Most of the information about 16-bit and static 32-bit technologies was moved to the Library Archive in January 1997.
