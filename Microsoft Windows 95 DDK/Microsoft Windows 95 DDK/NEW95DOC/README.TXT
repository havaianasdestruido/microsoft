May 1998

This folder contains documents from the Win95 DDK original DOC folder that have been updated by the OEM/IHV DDK Developer Support team.  All updated documents are in Word 97 document format.  A free Word 97 viewer can be downloaded from www.microsoft.com; conduct a Search at http://www.microsoft.com using the following keywords: Word Viewer 97.

The following are documents that are new or are enhancements of the original:
COMM.DOC         - A rewritten, augmented version of the old VCOMM.DOC.
DISPLAY.DOC      - Reformatted Display Driver technology.
GRAPHCNT.DOC     - Reformatted Graphics Device Drivers technology.
INTRO.DOC        - Updated and combined GETSTART.DOC, DGINTRO.DOC and PGINTRO.DOC.
KERNEL.DOC       - Virtual Machine Manager (VMM).
KEYCNT.DOC       - Reformatted Keyboard Drivers technology.
MMEDIA.DOC       - Reformatted Audio Adapter, Input devices and Video Capture technology.
STORAGE.DOC      - Local Storage technology.
UTILS.DOC        - Debugging tools (WDEB386 etc.).
VXDS.DOC         - Updated and combined VXD.DOC and WIN95OVR.DOC.

The "Faq" subdirectory contains new Windows 95 DDK "Frequently Asked Questions" documents.

In order to distinguish between the original documentation and updates that have been made, several amended documents are updated using the Word 97 "Review" feature (except COMM.DOC). The review feature highlights all amendments using color and underscores.

If you want to remove the highlighting (thereby "accepting" the review text), click on Tools / Track Changes / Accept or Reject Changes, then click the "Accept All" button.

You can add your own "review" text, using Word 97.  Click on View / Toolbars / Reviewing.  This will make the Reviewing toolbar appear above the document.  Click on the "track changes" icon, then begin typing your "review" text.
